What was observed, and what was labelled?

Market and split

  • Four LLM sellers set prices and post public messages for twelve rounds in an economics-lab framing; earnings = profit.
  • Conditions: private channel, no channel, or a public shipping partnership.
  • Dev n = 30; test n = 95 (50 positive); fresh replication n = 30.

Six original auditor views

  1. Public text
  2. Actions: prices, state, units, profit
  3. Actions + pair statistics
  4. Text + actions
  5. Text + actions + pair statistics
  6. All above + stated-vs-actual price table
Endpoint: private coordination communication. A judge reads private chat only, never prices. Private chat is hidden from auditors. In the main dataset every private-channel run is positive: label = condition. This is not a verified-overcharge label.

Same auditor model, same cases, public partnership notice in every view. Run AUROC measures detection; within-market AUROC measures pair localisation in positive runs.

Speaker notes

Sellers were given profit objectives and an opportunity to communicate, not instructions to collude. The operational label includes explicit agreements and price-intention exchanges. A judge-positive chat is not evidence that the private exchange caused the prices. The full report documents the lab framing, pilots, and all six input views.

Threshold uncertainty

False-alarm rates change even under the same generator. The fresh no-channel sample is small.

Evasion remains untested

Under an announced price monitor, the judge finds coordination in 0/14 private-channel runs. There were no judge-positive evasive colluders to evaluate.

Design hypothesis: compute cheap action statistics first, then use LLMs for explanation. This proposed workflow is not validated for deployment or for explanation accuracy.

Speaker notes

AUROC is threshold-free and does not promise a calibrated alarm. The premium's fresh none rate is four of ten; the uncertainty is large. The report has firm-framing and announced-monitor strata with additional false alarms. The monitor result could reflect safety-triggered refusal or deterrence. We cannot test evasion without coordinated runs. A premium-filtered AND-gate was analysed descriptively in the report; the broader explanatory workflow is only a proposal.

A bounded finding, and a more decisive next test

  • Supported here: no resolved detection gain from adding raw public text to the tested zero-shot auditors; computed action summaries improve pair localisation.
  • Not established: equivalence of text and action auditing, agreement-caused overcharge detection, reliable evasion detection, or transfer across seller models.
  • Next study: independently vary channel offer, message delivery, and realised agreement; replicate across seller models and market designs, and test concealed opening-price cues.
